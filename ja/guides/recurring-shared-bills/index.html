周期・支出・返済を区別する

Loop は周期、支払者、分担を保存します。支出は費用を記録し、同期後に残高へ反映されます。返済は、アプリ外でメンバー同士がすでに支払ったお金を記録します。LoopSplit は銀行への接続やサービス提供会社への支払いを行いません。

家賃とネット代の例

Alex と Sam が家賃 1,800 とネット代 60 を均等に分けます。Alex が両方を払うと、各自の負担は 930。ほかに記録がなければ、Sam は Alex に 930 を返します。アプリ外で支払ったら返済を 1 件記録し、新たに 930 の共有支出を追加しません。

定期的な費用を Loop にする

  1. ブックで Loop を作り、金額または金額の扱い方を選びます。
  2. 周期、支払者、参加者、分担を保存します。
  3. 対象期間の期日が来たら To Do を開き、金額を確認して記録します。
  4. 同じ期間を再度記録する前に履歴を確認します。

無料ブックで使える有効な Loop は最大 3 件で、Pro ではこの件数制限がなくなります。期日が来ても、請求の支払い済みや銀行の自動引き落としを意味するわけではありません。

金額が変わったら、同じ記録を更新

変動する請求には実際の金額を使います。Pro では概算の支出も利用できます。概算でも保存・同期した時点で残高に含まれ、金額の確定時は同じ記録が更新されて残高が再計算されます。確定額で 2 件目の支出を作らないようにしましょう。レシート写真の添付と閲覧は無料です。

金額は米ドル（USD）で、説明のための例です。
