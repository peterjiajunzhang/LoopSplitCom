Set up LoopSplit with MCP

Add LoopSplit as a custom connection to check who owes whom in your shared expense Books. You’ll need a LoopSplit account with a verified email and at least one Book.

MCP server URL
https://mcp.loopsplit.app/mcp
Copy this URL into your assistant’s custom connection settings.

Connect ChatGPT

Use ChatGPT on the web. Your account and workspace settings determine whether you can add a custom MCP server.

  1. Open ChatGPT Plugins. Select +, then Add custom MCP server.
  2. Enter LoopSplit as the name and a description such as “Shared expense Books.”
  3. Under Connection, choose a public endpoint and paste the MCP server URL above. Select OAuth for authentication. If asked how to register, choose Dynamic Client Registration (DCR).
  4. Review the warning, continue, then select Create as a plugin. Review the tools and install the private plugin you just created.
  5. When prompted, sign in to LoopSplit and choose which Books and permissions to share.
  6. Start a new chat, type @, and select the LoopSplit connection you created.

If you need help finding these controls, see OpenAI’s custom MCP setup steps.

Connect Claude

  1. Open Customize → Connectors in Claude. Select Add, then Add custom connector.
  2. Enter LoopSplit as the name, paste the MCP server URL above, and select Continue.
  3. Use OAuth. If Claude asks how to register its OAuth client, choose Register automatically. Then select Add.
  4. Select Connect when prompted, sign in to LoopSplit, and choose which Books and permissions to share.
  5. In a chat, open + → Connectors and turn on LoopSplit for the conversation.

For a Team or Enterprise workspace, an owner or authorized administrator can add the custom connector for the organization. Members then connect with their own LoopSplit accounts. See Claude’s custom connector setup steps.

Connect another assistant

Your assistant needs to support remote MCP servers over Streamable HTTP and OAuth sign-in.

  1. In the assistant’s settings, add a custom MCP server and paste the URL above.
  2. Choose OAuth if asked, then start the connection from the assistant.
  3. Sign in on the LoopSplit page and choose which Books and permissions to share.

Choose Books and permissions

Whichever assistant you use, connecting opens a LoopSplit page that shows the app’s name, the address it will send you back to, and the access it requests.

  1. Under Choose books to share, select at least one Book. Books you do not select stay invisible to the assistant.
  2. Under Allow permissions, start with Read books and entries only. Leave Add and change entries off for balance checks and other lookups.
  3. Choose Allow access.

The page may also list identity items such as confirming your identity, viewing your basic profile or email address, and staying connected until you revoke access. Check the address the page says you will return to. If the page warns that the request returns to an app on your own device, continue only if you started it yourself a moment ago.

You need a Book before you can connect an assistant. The request expires after a few minutes; if it does, start the connection again from the assistant.

Check your balances

In a chat with the connection enabled, try “Using LoopSplit, who owes whom in my Home Book?” Replace “Home” with the name of a Book you shared. You can also ask “What are the last five entries in Home?” or “Which Loop bills are coming up in Home?”

Disconnect an assistant

  1. Open Account in the LoopSplit web app and sign in if prompted.
  2. Find Connected apps.
  3. Find the app, check its permissions and Books, and choose Revoke access, then confirm.

What happens: the app loses access to the selected Books and stops working, and LoopSplit asks the sign-in provider to cancel the tokens it issued to that assistant. Entries already saved stay in the Book until changed or deleted in LoopSplit. Data the AI provider already received remains subject to its privacy policy and controls.

The assistant may still list the connector. Remove it in the assistant’s own settings if you want it removed there. You can connect again later and choose different Books or permissions.

Preview, then confirm

LoopSplit will not record an entry or save a change unless it matches a preview, and it tells the assistant to show you that preview and wait for your go-ahead.

  1. You ask for an expense, income, repayment, Loop period or a change to an entry. The assistant asks LoopSplit for a preview.
  2. LoopSplit returns the exact amount, each member’s share and the resulting balances. For a change, it shows each field from old to new, and says if someone else recorded the entry or a Loop created it. The assistant shows you these. A preview is valid for 10 minutes and can be used once.
  3. If it is right, confirm. If you see a confirmation card, use its confirm button to save the entry. With a text preview, reply in the chat to confirm. If the details change or the preview expires, ask for a new preview.

What happens: the entry appears in the Book like any other, and balances update after LoopSplit applies it. If the assistant says an entry is saved but balances are not applied yet, wait and check the Book. Do not ask for a duplicate.

Your assistant controls how it shows the preview and asks for your approval. Check the Book, amount, currency, date, payer and split before confirming. You can correct an entry in the LoopSplit app or web app.

Read-only or read & write

PermissionThe assistant can
Read books and entriesList the Books you shared, show members and balances, list and search entries, and show Loop bills and their recorded status. It cannot change anything.
Add and change entries (in addition to read)Also preview and, after you confirm, record expenses, income, repayments and a due Loop period, and change one existing entry at a time, in the Books you shared.

An assistant cannot delete entries, manage Loops or members, create or leave Books, or attach or view receipt photos; after an entry is saved it can give you a link to that entry in the web app, where you can add a receipt. LoopSplit records repayments made outside the app. It does not transfer money or connect to banks.

What the assistant can see

For the Books you selected, the assistant receives what LoopSplit returns for its requests: the Book’s name and currency, members’ display names and internal member IDs (each is that member’s LoopSplit account ID), balances, entries (titles, amounts, dates, who paid, each member’s share, categories, who created each entry and whether a receipt is attached) and Loop bill status. It does not receive receipt photos or your password. LoopSplit does not return other members’ email addresses to the assistant. If the assistant requests the OpenID Connect email scope and you approve the connection, Stytch may share your own verified LoopSplit email address with the assistant during sign-in.

That data is sent to the AI service you are using, at your request, and that company’s terms and privacy policy apply to how it handles it. Shared Books: any member of a shared Book can connect an assistant to it, and then when the assistant retrieves entries, the other members’ names, amounts and entry titles can be shared with that member’s AI service without asking or notifying the other members. Entry titles can contain personal details about other members, so connect only Books you and the other members are comfortable discussing with that service, and tell the other members if you do. See the Privacy Policy for how LoopSplit handles information, including the sign-in provider that completes the connection.

If something goes wrong

  • The connection page says the request is invalid or expired, or that app connections are not configured yet. Start the connection again from the assistant. Confirm that you entered the address exactly.
  • The assistant says a Book is not authorized. You did not select it, or the permission is missing. Revoke the connection and connect again, choosing the Book.
  • The assistant cannot record an entry. Connect again with Add and change entries turned on, or ask for a new preview if the old one expired.
  • Search seems incomplete. For large Books the assistant searches a limited number of recent entries and should tell you when a result may be incomplete.

Use the web app

Open the LoopSplit web app and sign in with the same account you use on mobile. The web app lets you manage Books and Loops, record or edit entries, and attach receipts.

Mobile app features

Use the mobile app to scan receipts or to purchase or restore LoopSplit Pro.
