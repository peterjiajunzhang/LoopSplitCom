Set up LoopSplit with MCP

Add LoopSplit as a custom connection to check who owes whom in your shared expense Books. You’ll need a LoopSplit account with a verified email and at least one Book.

MCP server URL
https://mcp.loopsplit.app/mcp
Copy this URL into your assistant’s custom connection settings.

Connect ChatGPT

Use ChatGPT on the web. Your account and workspace settings determine whether you can add a custom MCP server.

  1. Open ChatGPT Plugins. Select +, then Add custom MCP server.
  2. Enter LoopSplit as the name and a description such as “Shared expense Books.”
  3. Under Connection, choose a public endpoint and paste the MCP server URL above. Select OAuth for authentication. If asked how to register, choose Dynamic Client Registration (DCR).
  4. Review the warning, continue, then select Create as a plugin. Review the tools and install the private plugin you just created.
  5. When prompted, sign in to LoopSplit and choose which Books and permissions to share.
  6. Start a new chat, type @, and select the LoopSplit connection you created.

If you need help finding these controls, see OpenAI’s custom MCP setup steps.

Connect Claude

  1. Open Customize → Connectors in Claude. Select Add, then Add custom connector.
  2. Enter LoopSplit as the name, paste the MCP server URL above, and select Continue.
  3. Use OAuth. If Claude asks how to register its OAuth client, choose Register automatically. Then select Add.
  4. Select Connect when prompted, sign in to LoopSplit, and choose which Books and permissions to share.
  5. In a chat, open + → Connectors and turn on LoopSplit for the conversation.

For a Team or Enterprise workspace, an owner or authorized administrator can add the custom connector for the organization. Members then connect with their own LoopSplit accounts. See Claude’s custom connector setup steps.

Connect another assistant

Your assistant needs to support remote MCP servers over Streamable HTTP and OAuth sign-in.

  1. In the assistant’s settings, add a custom MCP server and paste the URL above.
  2. Choose OAuth if asked, then start the connection from the assistant.
  3. Sign in on the LoopSplit page and choose which Books and permissions to share.

Choose Books and permissions

  1. Under Choose books to share, select one Book to try.
  2. Under Allow permissions, keep Read books and entries selected. If Add and change entries is already selected, clear it. Read access is enough to check balances and look up entries.
  3. Review the app name and return address, then choose Allow access.

Check your balances

In a chat with LoopSplit enabled, ask “Using LoopSplit, who owes whom in my Home Book?” Replace “Home” with the name of the Book you shared.

Disconnect an assistant

Open Account in the LoopSplit web app. Under Connected apps, find the assistant, choose Revoke access, then confirm. The assistant loses access to your Books. Saved entries stay in LoopSplit, and data already sent stays subject to the AI provider’s privacy controls.

Preview and confirm changes

Add and change entries allows a compatible assistant to record an expense, income, a repayment already made, or one due Loop period, or edit one existing entry at a time. LoopSplit requires a matching preview for each save.

Check the Book, amount, date, payer and split before confirming. If your assistant shows a confirmation card, use its confirm button. If it shows a text preview, confirm in the chat. Ask for a fresh preview if the details change or 10 minutes have passed.

What the assistant can see

For Books you share, an assistant can retrieve Book names, currencies, member display names and IDs, balances, entry details and recurring bill status. Entry titles can contain details about other members. The assistant can see whether an entry has a receipt attached. Receipt photos and other members’ email addresses stay in LoopSplit. Depending on the sign-in permissions you approve, the assistant may also receive your verified email.

Data returned to an assistant is subject to the AI provider’s privacy policy. See the LoopSplit Privacy Policy.

Troubleshooting

  • The connection expired. Start again from the assistant and check the server URL.
  • A Book is missing. Revoke access and reconnect, selecting that Book.
  • You can read balances but can’t save an entry. The assistant must support writes, your workspace must allow them, and Add and change entries must have been granted. Some ChatGPT accounts, including personal Pro accounts, may only have read access. If your assistant offers read access only, record the entry in LoopSplit.

For direct access to your Books, open the LoopSplit web app. For connection help, contact support.
