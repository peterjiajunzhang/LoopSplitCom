分清周期、支出和还款

Loop 保存费用的周期、付款者和分摊安排；支出记录实际成本并在同步后影响余额；还款记录成员在应用外已经支付给彼此的钱。LoopSplit 不连接银行，也不支付服务商或实际转账。

每月房租和网络费的例子

Alex 和 Sam 均分 1,800 的房租及 60 的网络费。如果两笔费用均由 Alex 支付，记入并同步后，每人份额为 930；没有其他记录时，Sam 应还 Alex 930。Sam 在应用外支付后，记录一次还款即可，不需要再添加一笔 930 的共同支出。

为重复费用设置 Loop

  1. 在账本中创建 Loop，选择金额或金额处理方式。
  2. 保存周期、付款者、参与者和分摊方式。
  3. 本期到期后，打开待办，核对金额再记录。
  4. 记录前查看本期历史，避免同一期重复入账。

每个免费账本最多有 3 条启用中的 Loop，Pro 可解除这项数量限制。到期不等于已支付账单，也不等于自动从银行扣款。

账单金额变了，更新同一笔记录

水电费可以按账单实际金额记录。Pro 也支持先记估算金额：估算支出保存并同步后已经计入余额；确认最终金额时更新同一笔记录并重新计算余额。不要把最终金额另记成第二笔支出。收据照片可免费附加和查看。

金额均为美元（USD），仅为说明性示例。
